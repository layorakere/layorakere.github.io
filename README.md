# Layor Akere - Data Analysis Portfolio

Welcome! This repository contains the complete template for a professional, one-page data analysis portfolio website, hosted for free on GitHub Pages.

## About This Portfolio Template

This portfolio brings together selected data analytics projects that reflect my growing experience with SQL, Power BI, Excel, data visualisation, and dashboard development. Each project highlights how I worked with data, explored patterns, and communicated findings through clear and interactive reports.

## 🚀 Projects

This template is set up to showcase your best work. You can easily customize the project cards in the `index.html` file.

### End-to End Logistics performance Analytics
An end-to-end logistics analytics project using SQL and Power BI to examine customer profitability, route performance, driver safety, fleet utilisation, and operational efficiency.

### Sales & Customer Insights
An interactive Power BI dashboard analysing sales performance, profitability, customer activity, brand performance, and purchasing patterns.
### Betting Addiction Among Nigerians
A data analysis project exploring betting behaviour across age groups, locations, betting platforms, and addiction scores.
